Wykład 1

Podstawy składni i typów

Wiązania w Haskellu się nie zmieniają. Funkcje wywołujesz spacjami, a aplikacja wiąże mocniej niż operatory. Obie gałęzie if muszą mieć ten sam typ. GHC jest kompilatorem; w konsoli GHCi użyjesz :type, by zobaczyć typ wyrażenia.

sign n
  | n < 0     = -1
  | n == 0    = 0
  | otherwise = 1
Skąd się bierze typ funkcji z ==?

Dla same x y = x == y otrzymujesz Eq a => a -> a -> Bool. Operator wymaga dwóch wartości tego samego typu i instancji Eq.

Sprawdź się: square 2 + 3 przy square x = x*x

7. Najpierw square 2, potem dodawanie. Dla wyniku 25 zapisz square (2+3).

Wykład 2

Listy, leniwość i rekurencja

a -> b -> c oznacza a -> (b -> c). Podanie jednego argumentu może zwrócić funkcję. Listę rozbijasz na [] albo (x:xs). Z take możesz pobrać skończony fragment listy nieskończonej.

sumOwn [] = 0
sumOwn (x:xs) = x + sumOwn xs

[x*x | x <- [1..6], even x]   -- [4,16,36]
Dlaczego take 1 (7 : undefined) nie zgłasza błędu?

Wynik to [7]. Pierwszy element jest dostępny; nie trzeba wymuszać ogona. Podobnie WHNF listy rozróżnia [] od (:), bez liczenia elementów.

Wykład 3

Funkcje wyższego rzędu i foldy

map zmienia elementy, filter je wybiera, a fold zbiera wynik. zipWith łączy odpowiadające sobie elementy i kończy na krótszej liście. concat usuwa jedną warstwę list. Złożenie czytaj od prawej: poniżej filtr → kwadraty → suma.

sum . map (^2) . filter even $ [1..5]  -- 20

foldr1 (-) [1,2,3,4] -- 1 - (2 - (3 - 4))
foldl1 (-) [1,2,3,4] -- ((1 - 2) - 3) - 4
„Od prawej” — czy odwracamy listę?

Nie. Liczby dalej stoją w kolejności 1, 2, 3, 4. Nawiasy w foldr1 zagnieżdżają się z prawej: 3-4=-1, potem 2-(-1)=3, na końcu 1-3=-2.

Sprawdź się: map even [1,2,3] kontra filter even [1,2,3]

Pierwsze daje [False,True,False], drugie [2]. filter zachowuje oryginalne elementy.

Wykład 4

Typy algebraiczne, klasy i moduły

  1. type nadaje drugą nazwę temu samemu typowi; newtype odróżnia go przy jednym konstruktorze i polu; data pozwala na wiele wariantów i pól.
  2. Konstruktor z polami to funkcja. Dopasowanie wzorca rozkłada wartość na pola. Selektor rekordu jest funkcją; aktualizacja rekordu zwraca nową wartość.
  3. Maybe wyraża możliwość braku wyniku. Drzewa i drzewa wyrażeń opisujesz rekurencyjnie.
  4. class określa metody, instance ich zachowanie dla konkretnego typu. deriving może wygenerować standardową instancję.
  5. Lista eksportu modułu określa, czy użytkownik może użyć konstruktora, czy tylko publicznych operacji.
data Shape = Circle Double | Rect Double Double
  deriving (Show, Eq, Ord)

area (Circle r) = pi*r*r
area (Rect w h) = w*h

safeHead []    = Nothing
safeHead (x:_) = Just x
Co zwraca maximum [Circle 3, Rect 1 1]?

Rect 1.0 1.0. Automatyczne Ord porównuje najpierw kolejność deklaracji konstruktorów. Jeżeli chcesz porównywać pola powierzchni, jawnie użyj area jako klucza.

Jak odróżnić klasę od instancji?

class HasArea a mówi, że istnieje operacja area. instance HasArea Disk określa wzór dla dysku. Dla klasy Ord typ musi mieć również instancję Eq.

Jak przejść po drzewie krok po kroku?
data Tree a = Empty | Node (Tree a) a (Tree a)
size Empty = 0
size (Node l _ r) = 1 + size l + size r

size schodzi do obu poddrzew. Wstawianie do BST wybiera tylko jedną stronę: mniejsze w lewo, większe w prawo. Sam konstruktor Node nie pilnuje porządku, więc można go ukryć w module.

Sprawdź się: co oznacza eksport Stack zamiast Stack(..)?

Widać nazwę typu, ale poza modułem nie można tworzyć wartości przez konstruktor Stack ani używać go we wzorcu. Zamiast tego używasz funkcji empty, push i pop.
