Notatki powstały na podstawie `fp-w1.md`, `_MConverter.eu_fp-w2-min.md` i `fp-w3.pdf`. Pominięto historię, organizację zajęć i zasady oceniania. Poprawiono zniekształconą składnię kodu oraz dodano przykłady i objaśnienia.

Fragmenty kodu są niezależnymi przykładami. Nie sklejaj wszystkich w jeden plik: niektóre zawierają alternatywne definicje lub celowe błędy do omówienia.
